Email addresses

Which account these emails send from, and where each "Email PDF" / "Email Selected" button sends to.

Must already be set up as an account in Mail.app on the shop Mac (Mail → Settings → Accounts) — this just tells Mail.app which of your existing accounts to send as. It can't create a new account or send from an address Mail.app doesn't already have credentials for. Leave blank to keep using whichever account is Mail.app's own default.
